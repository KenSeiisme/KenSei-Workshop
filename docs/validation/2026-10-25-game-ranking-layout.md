# 常驻排行榜与一站式开局验收

基线为 `8d394ce3345fe9a9f00bf502b13b70a5d4aefa06`。本次调整 12 款游戏的入口和表现，保留 9 款可排行游戏，不改变计分、规则、数据库、RPC 或 Edge Function。

## 实现

- 难度、电脑对手及先后手使用开局卡中的唯一一套控件；Start 始终主要，Continue 为次要，显示保存时间及 Legacy 标记。设置变化不创建会话。
- 移除 Public/Private 选择与独立进度面板。资格由身份和真实会话决定；登录新局自动参榜，游客、暂停、后台及恢复为本机游玩。下一局重新判断，避免被上一局的本机状态锁住。
- 开局失败有 Retry/Play locally，提交失败保留账号隔离的待提交结果。Verified 只来自服务端确认，完成后不会因会话释放而显示为 Local only。
- 排行榜位于舞台旁，宽度达到 1100px 为 300px 侧栏；更窄屏幕位于棋盘及操作区下方。专注模式保留榜单；Top 10/50、展开、刷新不暂停或重建棋盘。本人名次独立显示，旧规则榜保留。
- 排行榜采用独立模块，只在指定事件读取；过期请求不覆盖当前难度，失败保留同一榜单的已有内容。保留所有原始存档键、账号同步、冲突副本、游客明确导入、成就及 Profile。
