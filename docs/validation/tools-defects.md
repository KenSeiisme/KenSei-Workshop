## 测试维护

- 原第四批单元测试通过 data URL 加载后来新增相对 import 的模块，测试自身无法解析；改用真实模块 URL，保留原参考值断言。
- 旧界面脚本仍期待直接文字变换、隐藏的旧预设按钮和只读表格文本；改按当前 Preview → Apply、配方保存和单元格 value 验证，没有移除输出断言。
- OCR 取消测试不能依赖 400ms 延迟或嵌套 Worker 网络拦截；使用真实 Worker 的识别消息闸门，确定在处理期间取消，之后恢复真实模型失败/重试检查。
- Firefox 的失败保留在初次完整报告；另用不拦截 Worker/WASM/模型请求的连续取消确认并修复。修复后重新运行跨引擎输出组与 28 工具核心回归，不自动重试来隐藏失败。
- 响应式检查等待尺寸事件完成，并排除零面积节点，避免把尚未完成布局的隐藏标签误判为小触控目标。

## 已知边界

- 本轮不提供“零 Bug”保证或正式 WCAG 符合性认证。
- Windows Playwright WebKit 运行时缺少 Web Audio；其能力提示已验证，音频文件输出记不适用。Edge/Firefox 的真实音频输出另行验证，实体 Safari 不由此推断。
- Playwright 的 PDF 打印 API 仅覆盖 Chromium；Firefox/WebKit 验证相同 HTML/图形导出，原生 Save as PDF 仍需人工。
- PDF 中文/Unicode 文字导出嵌入完整字体，因此可能比源文件大；页数、坐标和可检索文字独立检查。
- 真实 Google 授权、Android 软键盘/设备权限、实际读屏和首次使用者理解按人工短清单记录。四个真实 Auth 身份的共享白板检查不由本机数据库或模拟频道替代。
