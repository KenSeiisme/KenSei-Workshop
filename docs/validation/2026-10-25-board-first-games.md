# 棋盘优先与专注模式验收

基线为 `d0896ea6975b925b196f3dc9d0a3a1e038e97fbc`。本次仅调整 12 款游戏页的表现和入口，不升级规则或发布数据库／Edge 更新。

## 界面与状态

- 小标题、模式摘要、声音及设置形成紧凑工具栏；HUD 改为单行。固定 SVG 待机预览不调用引擎、随机数或会话接口。
- Start／Continue 位于棋盘内。当前难度或指定存档支持明确的 Private／Legacy 恢复；New game 确认替换。开局失败保留预览、设置及重试，Public 待提交保护继续生效。
- 成功开始、恢复或加入 Pong 房间后自动专注。Exit focus 不暂停、不改变 Public 资格，不调用全屏或横屏锁定。暂停／结算保留舞台；Pong 中断保留场地与提示。
- 设置与操作菜单不自动暂停；Help／进度面板需要暂停时先向 Public 玩家确认。Escape 优先关闭弹层，回到棋盘后沿用原来的暂停行为。
- 共享舞台根据视口、操作区及安全区安排尺寸；保留棋盘节点与逻辑坐标。大型网格在容器内滚动；短横屏的下落方块与打砖块使用侧边操作区。主动聚焦不再自动滚动页面。
